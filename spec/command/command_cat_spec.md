# 極小UNIX `cat` 仕様書

| 項目 | 内容 |
|---|---|
| 文書ID | SUBSET-CAT-001 |
| 版 | 0.1（実装前ドラフト） |
| 対象 | サブセットOSの `/bin/cat` |
| 位置づけ | UNIX V7寄りの最小バイト列転送コマンド |

## 1. 目的と適用範囲

指定されたファイルを順番に読み取り、内容を変更せず標準出力へ連結して出力する。ファイル読み込み、部分読み書き、EOF、標準入出力およびファイル記述子の動作検証にも用いる。

## 2. 起動形式

```text
cat [-u] [file ...]
```

- `file` が指定されない場合、標準入力fd=0から読み込む。
- `file` が `-` に完全一致する場合、その位置で標準入力fd=0から読み込む。
- 複数の入力元は引数順に処理し、境界に改行などを自動挿入しない。
- `-n`、`-b`、`-s`、`-v` 等の加工オプションは対応しない。
- ファイル名のワイルドカード展開、クォート解釈は行わない（シェル側の責務）。
- **暫定:** `-u` は先頭に指定された場合のみ受け付け、何もしない互換オプションとする。先行検討では「未対応でエラー」とする案もあり、正式確定待ち。オプション終了記号 `--` の扱いも初版では規定しない。

## 3. 動作例

```text
cat
cat /etc/inittab
cat file1 file2
cat -
cat file1 - file2
```

`cat file1 - file2` は、`file1`、標準入力、`file2` の順に読み込む。同じ標準入力を複数回指定した場合は、同じfdの現在位置から読み続けるため、最初の `-` でEOFに達していれば後続の `-` は通常追加出力しない。

## 4. データ転送仕様

- バイナリ透過とする。NUL、改行、CR、非ASCIIを含め、読んだバイト列をそのまま書く。
- 転送バッファは固定長512バイトを推奨する（スタック上に配置）。ファイルサイズ上限は設けない。
- 各入力元に対し `read(fd, buffer, sizeof(buffer))` を繰り返す。
- `read()` が正値なら、そのバイト数すべてをfd=1へ出力する。短い読み込みはEOFとみなさず、次の`read()`を継続する。
- `read()` が0なら、その入力元のEOFとして終了する。
- `read()` が負値なら、その入力元の読み込みエラーとして扱う。
- `write()` の正の部分書き込みは残量を再送し、0または負値は書き込みエラーとして扱う。
- 各入力ファイルは`open(path, O_RDONLY, ...)`で開き、処理後は`close(fd)`する。OSの実際の`open()`シグネチャに従う。
- fd=0（標準入力）は`cat`自身が開いたFDではないため閉じない。

## 5. エラー処理

| 異常 | 処理 | 後続ファイル |
|---|---|---|
| ファイルの `open()` 失敗 | 診断表示、失敗を記録 | 続行 |
| `read()` 失敗 | 当該入力元を打ち切り、診断表示 | 続行 |
| `write()` が0または負値 | 診断表示、コマンド全体を中断 | 実行しない |
| 開いたファイルの `close()` 失敗 | 診断表示、失敗を記録 | 続行 |
| 不明なオプション | 診断表示し、コマンド開始前に異常終了 | 実行しない |

- 診断出力先は標準エラーfd=2。診断自体の失敗は追加処理しない。
- 複数ファイルの処理で失敗が1件でも発生した場合は、後続を処理しても最終終了ステータス1とする。
- 標準入力に対するreadエラーも同様に扱う。
- 正常終了時は0、エラー発生時は1とする。

## 6. 使用API・実装制約

| 区分 | API | 用途 |
|---|---|---|
| OSラッパ | `open()` | 入力ファイルを開く |
| OSラッパ | `read()` | バイト列入力 |
| OSラッパ | `write()` | fd=1への出力・fd=2への診断 |
| OSラッパ | `close()` | `cat`が開いたfdを閉じる |
| ilibc | `std::strcmp()` | `-`およびオプションを判定 |
| ilibc（必要時） | `std::strlen()` | 診断メッセージの長さ取得 |

- `FILE*`、`fgets()`、`printf()`、動的メモリ確保、シグナル機構は不要。
- ilibcの公開API追加は不要。
- 部分書き込みの再送ループはローカルの小さな補助関数にまとめてよい。
- fdの所有権を尊重し、標準入力を閉じない。

## 7. 受入テスト

1. 引数なしでstdinをstdoutへバイト単位で転送する。
2. 1ファイルおよび複数ファイルを順次、区切りを足さず連結する。
3. `-`指定により標準入力を転送する。
4. NULを含む入力や改行なしの最終行を無変換で出力する。
5. EOFは`read()==0`でのみ判定し、短い正のreadでも継続する。
6. 部分書き込みが発生しても重複・欠落なく出力する。
7. 存在しないファイルの後も次のファイルを処理し、最終戻り値は1とする。
8. read失敗時は当該ファイルを中断して後続へ進む。
9. write失敗時は全体を中止する。
10. `cat`が開いたファイルをcloseし、fd=0を閉じない。

## 8. 残課題・他仕様との整合

1. `-u` を無動作で許容するか、未対応として拒否するかは未合意。上記は前者を暫定採用。
2. ファイル名が `-` 以外で `-` から始まる場合の扱い、`--` の採否は未確定。実装前に規定することが望ましい。
3. `open()` のフラグと引数の厳密な定義、`errno`と診断文言はOS側syscall APIと一致させる。
