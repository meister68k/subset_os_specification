# 極小UNIX `echo` 仕様書

| 項目 | 内容 |
|---|---|
| 文書ID | SUBSET-ECHO-001 |
| 版 | 0.1（実装前ドラフト） |
| 対象 | サブセットOSの `/bin/echo` |
| 位置づけ | UNIX V7寄りの最小コマンド。POSIX完全互換は目指さない |

## 1. 目的と適用範囲

コマンドライン引数を標準出力へ書き出す。標準入出力、引数渡し、およびユーザープロセス終了の検証にも用いる。シェル構文の解析は行わない。

## 2. 起動形式

```text
echo [-n] [arg ...]
```

- `-n` は `argv[1]` に完全一致した場合にのみオプションとして認識し、末尾改行を省略する。
- `-n` 以外の文字列はすべて通常の引数として出力する。`--help`、`--version`、`-e`、`-E` および `--` の特別扱いはしない。
- 2番目以降の引数に現れる `-n` は通常文字列として出力する。
- 引数同士は ASCII スペース（0x20）1バイトで連結する。引数自身の内容は変更しない。
- 通常は出力の最後に LF（0x0A）1バイトを追加する。引数がない場合は LF だけを出力する。
- `echo -n`（出力対象引数なし）は0バイトを出力する。
- クォート、バックスラッシュ、変数展開、ワイルドカード展開は行わない。受け取った `argv` のバイト列をそのまま使用する。

## 3. 動作例

| 起動引数 | 標準出力（エスケープ表記） |
|---|---|
| `echo` | `\n` |
| `echo hello world` | `hello world\n` |
| `echo -n hello` | `hello` |
| `echo -n` | （0バイト） |
| `echo hello -n` | `hello -n\n` |
| `echo --help` | `--help\n` |

シェルがクォートを処理しないLevel 0段階では、引用符は `argv` 中の通常文字として残るため、`echo` もそのまま出力する。

## 4. 入出力仕様

- 書き込み先は標準出力 fd=1。通常は標準入力を参照しない。
- 書き込みにはOSの `write()` システムコールラッパを使用する。
- `write()` が要求量より少ない正のバイト数を返した場合、残りを繰り返し書く。
- `write()` が0または負値を返した場合は書き込み失敗として終了する。無限ループにしない。
- 出力をバッファにすべて構築する必要はなく、各引数と区切り、改行を順次書き込む。
- 文字列はNUL終端であることを呼び出し側の契約とする。埋め込みNULの出力は対象外。

## 5. エラーおよび終了ステータス

| 状況 | 処理 | 終了ステータス |
|---|---|---|
| 全書き込み成功 | 正常終了 | `0` |
| 標準出力への書き込み失敗 | 出力を中止する | `1` |

エラー時の診断メッセージは可能なら標準エラー出力（fd=2）へ出す。診断出力自体の失敗は追加の再試行やループを発生させない。診断文言は実装依存とし、終了ステータスは上表に従う。

## 6. 使用API・実装制約

- OSラッパ: `write()`、プロセス終了用ランタイム（`main()` の戻り値）。
- ilibc: `std::strlen()`（`<cstring>`）。追加のlibc APIは不要。
- `malloc` / `free`、`FILE*`、浮動小数点、シグナル機構、ファイルI/Oは不要。
- 実装は逐次書き込みとし、大きな固定バッファも不要。

## 7. 受入テスト

1. 引数なしの場合にLFのみ出力する。
2. 複数引数は単一スペースで連結し、末尾にLFを追加する。
3. 先頭 `-n` ではLFを付加しない。途中の `-n` は文字列として出力する。
4. `-e`、`--help`、引用符、バックスラッシュを特別扱いしない。
5. 部分書き込みを故障注入しても全バイトを順序通り出力する。
6. `write()` が0または負値を返すと終了ステータス1で終了する。

## 8. 未確定・留意事項

`echo` の `-n` やバックスラッシュの挙動にはUNIX実装間で差がある。本仕様はV7寄りの動作を意図的に選択したものであり、一般的なPOSIXシェルスクリプトの完全な互換性は保証しない。診断出力の厳密な文言は未規定。
