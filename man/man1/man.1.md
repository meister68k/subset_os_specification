# man(1)

## 名前
**man** — コマンドのマニュアルを表示する

## 書式
`man name`

## 説明
指定したコマンドのセクション1マニュアルを標準出力へ表示します。ページは`/man/man1/<name>.1.md`から読み込み、Markdownの基本的な装飾記号を省いて本文を出力します。

ページ全体を先頭から末尾まで連続して表示します。ページャー、画面クリア、キー入力によるページ送りは使いません。

`name`にはbasenameだけを指定します。section番号、`.1`、`.1.md`、directory prefixは付けません。大文字小文字は区別されます。

## 引数
- `name`: 表示するマニュアルのbasename。`/`を含む名前は指定できません。

## 使用例
```sh
man cat
man sh0
man PID
man man
```

## 終了ステータス
- `0`: マニュアルを最後まで表示
- `1`: 引数不正、ページが存在しない、または読み込み・表示に失敗

## 関連項目
`cat(1)`, `sh0(1)`, `wc(1)`
