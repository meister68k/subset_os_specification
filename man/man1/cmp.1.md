# cmp(1)

## 名前
**cmp** — 2つの入力をbyte単位で比較する

## 書式
`cmp [-s] file1 file2`

## 説明
2つの入力を先頭から比較し、最初の不一致を報告します。`file1`が`-`なら標準入力を読みます。`file2`の`-`は通常のファイル名です。NULや改行もbyteとして比較します。短いreadはEOFではありません。

一致時は無出力です。不一致時（通常モード）は標準出力に`file1 file2 differ: char N, line M`を出します。位置と行番号は1始まりです。片側EOF時は短い方を標準エラーで示します。

## オプション
- `-s`: 差分・エラー診断を抑止し、終了値だけを返します。

`-l`、`--`、長形式optionは非対応です。

## 終了ステータス
- `0`: 一致
- `1`: 内容または長さが不一致
- `2`: 引数、I/O、open/close等のエラー

## 使用例
```sh
cmp file1 file2
cmp -s expected actual
cmp - input.bin
```
