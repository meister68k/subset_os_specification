# cat(1)

## 名前

**cat** — ファイルを連結して標準出力へ書き出す

## 書式

```text
cat [-u] [file ...]
```

## 説明

**cat** は入力を順に読み込み、内容のbyte列を変更せず標準出力へ書き出します。入力元の間に区切りや改行は追加しません。

`file`を指定しない場合は標準入力を読み込みます。`file`が単独のハイフン（`-`）の場合も、その位置で標準入力を読みます。`-`を複数回指定した場合は、同じ標準入力の現在位置から読み続けます。

NUL、改行、CR、非ASCII byteを含め、読み込んだ内容をそのまま転送します。入力は固定長の塊で読み込み、短いreadをEOFとはみなしません。EOFはreadが0を返したときです。

## オプション

### `-u`

先頭引数として指定した場合に受け付けます。動作に影響しない暫定的な互換オプションです。

これ以外のオプションには対応しません。不明なオプションがあれば、入力処理を始める前にエラーを返します。`--`と、`-`以外のハイフンで始まるファイル名の扱いは未規定です。

## 入力

標準入力が`ConsoleDevice`の場合、入力echoはデバイス共通のecho設定に従います。既定のecho設定では、**cat**が標準出力へ書く前に入力文字が表示されることがあります。

コンソールのreadは要求したbufferが満たされるかEOFに達するまで戻らないため、出力はbufferが満たされるかCtrl-Dが入力されるまで遅れることがあります。この点はLinuxの端末動作と異なります。

Ctrl-DはコンソールのEOFとして扱われ、出力には含めません。同じreadでCtrl-Dより前にbyteが返された場合は、そのbyteを出力してから終了します。通常ファイル中の値`0x04`は通常のデータです。

## エラー

- 入力ファイルを開けない場合、readに失敗した場合、またはcloseに失敗した場合は標準エラーへ診断を出します。後続の入力元は処理を続けますが、いずれかでエラーが起きれば最終終了ステータスは失敗です。
- 標準出力へのwriteが0または負値を返した場合は診断し、処理を直ちに中止します。
- 正の部分書き込みがあった場合は、残りのbyteを書き込みます。

## 終了ステータス

| 値 | 意味 |
|---:|---|
| `0` | すべての入力を処理し、エラーがなかった |
| `1` | オプション、入力、出力、またはcloseでエラーがあった |

## 使用例

```sh
# 標準入力を標準出力へコピー
cat

# 1つのファイルを出力
cat /etc/inittab

# 2つのファイルを区切りなしで連結
cat file1 file2

# file1、標準入力、file2の順に出力
cat file1 - file2
```

## 注記

転送bufferは固定長512 byteです。**cat**自身が開いたファイルはcloseしますが、標準入力はcloseしません。
