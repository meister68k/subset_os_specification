# wc(1)

## 名前
**wc** — 行数・単語数・byte数を数える

## 書式
`wc [-l] [-w] [-c] [file ...]`

## 説明
入力の行数、単語数、byte数を数えて標準出力へ表示します。fileを省略すると標準入力を読み込むため、pipeの入力にも使えます。`-`は標準入力を表します。

行数はLF byteの数です。単語は空白で区切られたbyte列で、空白判定は`isspace()`に従います。CRも空白です。byte数は文字コードに関係なく入力byteを数えます。

複数fileを指定した場合は引数順に処理し、各入力について1行ずつ結果を表示します。総計行は表示しません。

## オプション
- `-l`: 行数を表示します。
- `-w`: 単語数を表示します。
- `-c`: byte数を表示します。

optionを指定しない場合は、行数・単語数・byte数をすべて表示します。複数optionを指定した場合の出力順は`-l`、`-w`、`-c`です。連結optionと`--`は未対応です。

## 出力形式
選択されたカウンタを10進表記し、空白1個で区切って表示します。fileを指定した場合は最後のカウンタの後にfile名を表示します。各結果はLFで終わります。

## 終了ステータス
- `0`: 全入力の処理と出力に成功
- `1`: 引数、open/read/write/close、またはカウンタoverflowのエラー

## 使用例
```sh
wc < file
echo hello | wc
wc -l -c file
cat file | wc -w
```
