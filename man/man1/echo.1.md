# echo(1)

## 名前
**echo** — 引数を標準出力へ表示する

## 書式
`echo [-n] [arg ...]`

## 説明
引数をASCII空白1個で連結して出力します。通常は末尾にLFを付けます。引数がない場合はLFだけを出力します。引用符やバックスラッシュを解釈せず、受け取った引数をそのまま出力します。

## オプション
- `-n`: argv[1]に完全一致する場合、末尾LFを省略します。後続引数の`-n`は通常文字列です。

`-e`、`-E`、`--`、変数・glob展開は非対応です。

## 終了ステータス
- `0`: 出力成功
- `1`: 標準出力へのwrite失敗

## 使用例
```sh
echo hello world
echo -n ready
```
